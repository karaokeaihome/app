使用方法

  1. 打开应用 → 工具 → 歌唱舞台。
  2. 用邮箱免费注册并设置名字。
  3. 在录音棚演唱后点击 🌟 发布到歌唱舞台。
  4. 收听大家的歌，送爱心、送花、评论并邀请合唱。
