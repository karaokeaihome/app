用电脑为音箱安装软件

音箱安装工具可一键为音箱安装完整的最新版 Karaoke AI Home（界面、AI 助手 Lambo、应用），之后也能一键更新。

需要：Windows 10/11 或 macOS 11 及以上的电脑、互联网、与音箱相同的 Wi‑Fi，以及音箱遥控器。

下载 Windows 版下载 macOS 版

1. 下载并打开软件

Windows

  1. 点击 下载 Windows 版，得到 KaraokeAIHome-CaiLoa.exe。如浏览器询问，选择 保留。
  2. 双击下载的文件。
  3. 如出现 “Windows 已保护你的电脑”：点击 更多信息 → 仍要运行。
  4. 音箱安装工具窗口打开。

macOS

  1. 点击 下载 macOS 版，打开 zip 解压出 KaraokeAIHome-CaiLoa。
  2. 双击该文件。
  3. 如 macOS 提示无法验证而不能打开：点击 完成，进入 系统设置 → 隐私与安全性，向下滚动点击 仍要打开，再点 打开。
  4. 会出现一个终端窗口（安装期间请勿关闭），软件在浏览器中打开。

2. 在音箱上打开 USB 调试（只需一次）

打开音箱并连接到与电脑相同的 Wi‑Fi，然后用遥控器按图操作。音箱菜单可能是中文、英文或其他语言，位置相同。

3. 安装

以后的更新

有新版本时，再次打开软件：有更新的音箱会显示 更新 按钮。软件总是从服务器获取最新版本，只有在提示软件本身有新版本时才需要重新下载。已安装的音箱也可以在手机 App 中用“更新音箱软件”自行更新。

找不到音箱？

  1. 音箱和电脑必须在同一个 Wi‑Fi。访客网络通常会阻止设备互相发现。
  2. 在音箱的“开发者选项”中，把 USB 调试关闭后再打开。
  3. 仍然找不到？请在下方输入音箱的 IP 地址（音箱的 设置 → 网络）。

注意事项

  • 软件只会安装到支持的音箱型号。其他型号只会提示，不做任何更改。
  • 安装过程中请勿关闭音箱。连接中断时软件会自动重试；仍失败时请点击 重试。
