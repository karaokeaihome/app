パソコンでスピーカーのソフトをインストール

スピーカー設定ツールは、最新の Karaoke AI Home 一式（画面、AI アシスタント Lambo、アプリ）をスピーカーにインストールし、その後の更新もワンクリックで行います。

必要なもの: Windows 10/11 または macOS 11 以降のパソコン、インターネット、スピーカーと同じ Wi‑Fi、スピーカーのリモコン。

Windows 版をダウンロードmacOS 版をダウンロード

1. ソフトをダウンロードして開く

Windows

  1. Windows 版をダウンロード をクリックし、KaraokeAIHome-CaiLoa.exe を保存します。ブラウザーに聞かれたら 保存 を選びます。
  2. ダウンロードしたファイルをダブルクリックします。
  3. 「Windows によって PC が保護されました」 と出たら、詳細情報 → 実行 をクリックします。
  4. スピーカー設定ツールの画面が開きます。

macOS

  1. macOS 版をダウンロード をクリックし、zip を開いて KaraokeAIHome-CaiLoa を取り出します。
  2. そのファイルをダブルクリックします。
  3. 「確認できないため開けません」と出たら 完了 を押し、システム設定 → プライバシーとセキュリティ を下までスクロールして このまま開く → 開く をクリックします。
  4. ターミナルが開き（インストール中は閉じないでください）、ブラウザーにソフトの画面が表示されます。

2. スピーカーで USB デバッグをオン（一度だけ）

スピーカーの電源を入れてパソコンと同じ Wi‑Fi に接続し、リモコンで画像のとおりに操作します。スピーカーの表示は中国語・英語など他の言語の場合がありますが、項目の位置は同じです。

3. インストール

その後の更新

新しい版が出たらソフトをもう一度開きます。更新のあるスピーカーには 更新 ボタンが出ます。ソフトは常にサーバーから最新版を取得するため、ソフト自体の新しい版が出たと表示されたときだけ再ダウンロードしてください。インストール済みのスピーカーは、スマホアプリの「スピーカーのソフトを更新」でも更新できます。

スピーカーが見つからない場合

  1. スピーカーとパソコンは同じ Wi‑Fi に接続してください。ゲスト用ネットワークでは機器同士が見えないことがあります。
  2. スピーカーの「開発者向けオプション」で USB デバッグを一度オフにして、再度オンにしてください。
  3. それでも見つからない場合は、スピーカーの IP アドレス（スピーカーの 設定 → ネットワーク）を下に入力してください。

ご注意

  • 対応機種にのみインストールします。非対応機種は表示されるだけで、何も変更しません。
  • インストール中はスピーカーの電源を切らないでください。接続が切れると自動で再試行します。それでも失敗したら 再試行 をクリックしてください。
